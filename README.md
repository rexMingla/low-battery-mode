# low-battery-mode
Garmin Connect IQ app (Monkey C) for longer running activities when battery life is precious (ie. Ironman).

Available on the Garmin Connect IQ Store: [Low Power Recorder](https://apps.garmin.com/apps/43abf6d3-594d-4065-a9f5-6653c9d5b476)

## Using it
- **START/STOP** opens the start menu (start, select activity, GPS settings, quit). While recording it pauses and
  opens the pause menu (resume, save, GPS settings, discard).
- **BACK** exits the app before the activity has started.
- **UP/DOWN** switches between a minimal set of screens: time of day, activity time, distance and battery percentage.
- Activities: run, bike, swim, other.
- GPS settings let you trade accuracy for battery by choosing which satellite systems are used, on devices that
  support it.

## Requirements
- Connect IQ 3.0.0 or later. Built with Connect IQ SDK 9.3.0.
- The supported devices are listed in `manifest.xml`. That file is generated by the Monkey C extension, so add or
  remove devices through the extension rather than editing it by hand.

## Building
Open the folder in VS Code with the Monkey C extension. `.vscode/settings.json` sets the type check level to Strict,
and the code compiles cleanly at that level. To build one device from the command line:

```
monkeyc -f monkey.jungle -d fenix843mm -l 3 -w -o bin/low-battery-mode.prg -y <developer_key>
```
